# nh-ai-skills

Agent skills for teaching law students, lawyers, and instructors how skills
work. Each skill is a self-contained folder with a `SKILL.md`.

| Skill | What it does |
|---|---|
| [engagement-letter](engagement-letter/) | Drafts a client engagement letter for a fictional Utah firm, computes Utah answer deadlines for litigation matters, and produces a Word redline with real tracked changes. See its [presenter guide](engagement-letter/README.md). |

## Install

- **Claude.ai:** download the ready-made zip at
  [`extras/engagement-letter/engagement-letter.zip`](extras/engagement-letter/engagement-letter.zip)
  (or zip the skill folder yourself). Then upload it under **Settings > Capabilities > Skills**.
- **Claude Code:** copy the skill folder to `~/.claude/skills/`.

`extras/` holds presenter materials that are not part of any skill: sample
outputs and the script that builds the letterhead.

All firms, people, and clients in these skills are fictional. This is teaching
material, not legal advice.
