# draft-complaint-utah extras

Maintainer tools. None of this is part of the skill, and none of it goes in the
zip you install.

- `template-capture.md`: how to fold what you learned on an approved complaint
  back into the skill's template, clause library, and checks. Keep it separate
  from drafting and run it on purpose.
- `evals/`: three made-up Utah matters with planted problems, plus answer keys,
  that test whether the skill catches what plain Claude misses. Use them as a
  model for writing evals from your own matters. See `evals/README.md`.
